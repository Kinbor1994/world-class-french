# Politique de Sécurité (Security Policy)

Le projet **World-Class French** accorde la plus haute importance à la protection des données des apprenants et à l'intégrité de ses intégrations d'infrastructure (base de données serverless Neon PostgreSQL, protocoles de synchronisation cloud).

---

## 1. Versions Supportées

| Version | Statut |
| :--- | :--- |
| Next.js 15 PWA (`app/`) | :white_check_mark: Support actif (Correctifs de sécurité prioritaires) |

---

## 2. Signalement d'une Vulnérabilité

Si vous découvrez une faille de sécurité ou une vulnérabilité potentielle (exposition de secret, injection SQL, faille XSS ou de validation d'API) :

1. **Ne publiez aucun rapport publiquement** dans les issues GitHub.
2. Envoyez immédiatement un courriel confidentiel à : `kinnoumeb@gmail.com`.
3. Précisez dans votre message :
   - La nature de la vulnérabilité ;
   - Le scénario de reproduction détaillé ;
   - L'impact potentiel sur les données ou la plateforme.

Nous nous engageons à accuser réception sous **48 heures** et à déployer un correctif dans un délai raisonnable.
